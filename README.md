# Take Our Kids to Work Day
We recently had a "Take Our Kids to Work Day." This is a day where children of our employees that are in grade 9 accompany their parents to their workplace to experience the environment. As part of this we quickly exposed them to what it is like to work on an Agile team.

# Super Hero Product
To support this agile concept we needed a product. Our product was creating a new super-hero. This super-hero would be defined by the team within the sprint and would need approval from our "product owner."

# Process
Prior to the kids arriving we had developed user stories and prepared our scrum board. Example stories included:
* As a super-hero I need a cool name so people want to hear stories about me
* As a super-hero I need an origin story so that I have a reason to be like I am
* As a super-hero I need powers so that I can defeat villians
* As a super-hero I need weaknesses so that I readers can have a sense of fear for me
* As a super-hero I need a look (skin, hair, gender, costume) so people can identify me
* As a marketer I need a social media presence so that I can market our upcoming super-hero
* As a super-villian I need a cool name to strike fear into the hearts of everyone
* As a super-villian I need an origin story so that I have a reason to be like I am
* As a super-villian I need a goal so that I have something evil to accomplish
* As a super-villian I need powers so that I can take over the world (or whatever my goals is)
* As a super-hero I need weaknesses so that I can be beaten
* As a super-villian I need a look (skin, hair, gender, costume) so people can identify me
* As a super-hero I need an sidekick because I can't always do it on my own
* As a sidekick I need a cool name so people want to hear stories about me
* As a sidekick I need an origin story so that I have a reason to be like I am
* As a sidekick I need powers so that I can defeat villians
* As a super-hero I need weaknesses so that I readers can have a sense of fear for me
* As a sidekick I need a look (skin, hair, gender, costume) so people can identify me
* As a marketer I need our first comic book cover so that I can really get people excited


We quickly went through a video of [Scrum concepts](https://www.youtube.com/watch?v=2Vt7Ik8Ublw) and assigned roles to the team; Scrum Master and Product Owner were employees. From there we quickly did sprint-planning, did some work, had a stand-up, did some more work, had a demo and a retrospective. All of this was in 30 minutes.

# What is this Project
This project was quickly developed (about 3 hours) to support the "social media presence" user story. The "model/hero.js" file is used to generate a JSON representation that is reflected on the root page.

As you modify the hero.js file the page will automatically reload and display all of the changes that you have made.

#Starting the Project
After running `npm install` all you need to run is `npm run dev`
